Análise de Evasão Escolar

Trabalho de Conclusão de Curso — Predição de evasão escolar utilizando Machine Learning

📖

Sobre o Projeto

Este projeto de TCC (Trabalho de Conclusão de Curso) foi desenvolvido como parte da minha formação em Licenciatura em Informática pelo IFRN. O objetivo principal foi criar um modelo preditivo capaz de identificar alunos com alta probabilidade de evasão escolar, permitindo que a instituição tome medidas preventivas.

Utilizando técnicas de Ciência de Dados e Machine Learning, o sistema analisa dados acadêmicos e socioeconômicos dos estudantes para gerar previsões com alta acurácia sobre quais alunos estão em risco de abandonar o curso.

🎯

O Problema

A evasão escolar é um dos maiores desafios enfrentados por instituições de ensino no Brasil. Identificar precocemente os alunos em risco de evasão permite ações preventivas, como tutoria personalizada, assistência financeira ou acompanhamento psicopedagógico.

💡

A Solução

Um sistema baseado em algoritmos de Machine Learning que recebe dados históricos de alunos e retorna uma probabilidade de evasão. O modelo foi treinado com dados reais, limpados e pré-processados com Pandas e avaliados usando métricas como acurácia, precisão e recall.

🛠️

Tecnologias Utilizadas

Python Linguagem principal do projeto
Pandas Manipulação e análise de dados
Scikit-Learn Modelagem e treinamento dos algoritmos de ML
Matplotlib / Seaborn Visualização de dados e gráficos
Jupyter Notebook Ambiente de experimentação interativa
⚙️

Fluxo do Projeto

1
Coleta de Dados

Extração de dados acadêmicos e socioeconômicos dos alunos do IFRN

2
Pré-processamento

Limpeza, normalização e tratamento de dados ausentes com Pandas

3
Análise Exploratória

Visualização de padrões e correlações nos dados

4
Treinamento do Modelo

Seleção e treinamento de algoritmos com Scikit-Learn

5
Avaliação e Resultados

Métricas de desempenho (acurácia, precisão, recall, F1-score)
