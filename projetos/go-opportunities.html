Go Opportunities

API REST de vagas de emprego construída em Go — aprendizado de backend moderno

📖

Sobre o Projeto

Este projeto é uma API REST completa para gerenciamento de vagas de emprego, desenvolvida inteiramente em Go (Golang). Foi criado como projeto de estudo para aprender os fundamentos e boas práticas de desenvolvimento backend com Go.

A API permite realizar operações CRUD (Create, Read, Update, Delete) em vagas de emprego, com persistência em banco de dados SQLite e documentação automática via Swagger.

🎯

Funcionalidades

✅ Criar novas vagas de emprego
✅ Listar todas as vagas disponíveis
✅ Buscar vaga específica por ID
✅ Atualizar informações de uma vaga
✅ Deletar vagas existentes
✅ Documentação interativa via Swagger
🔌

Endpoints da API

POST /api/v1/opening Criar vaga
GET /api/v1/opening Buscar vaga
GET /api/v1/openings Listar vagas
PUT /api/v1/opening Atualizar vaga
DELETE /api/v1/opening Deletar vaga
🛠️

Tecnologias Utilizadas

Go (Golang) Linguagem principal de alto desempenho
Gin Framework HTTP web minimalista e rápido
GORM ORM para Go — acesso simplificado ao banco
SQLite Banco de dados leve e embutido
Swagger Documentação interativa automática da API
📁
