Automação de Processos

Sincronização automática de cargos comissionados entre sistema Agili e Google Sheets

📖

Sobre o Projeto

Sistema em Python desenvolvido para a Prefeitura que automatiza a sincronização de dados de cargos comissionados. O sistema lê dados exportados do sistema Agili (em formato CSV) e atualiza automaticamente a planilha de controle no Google Sheets.

O robô cruza matrículas antigas com as novas, identifica quem foi exonerado, quem é novo e atualiza a planilha de forma inteligente — eliminando o trabalho manual repetitivo e propenso a erros.

🎯

O Problema

O setor de RH da Prefeitura precisava atualizar manualmente uma planilha de cargos comissionados todo mês, cruzando dados de centenas de servidores entre o sistema Agili e o Google Sheets. Processo demorado, repetitivo e sujeito a erros humanos.

💡

A Solução

Uma automação em Python que, com um único comando, lê os CSVs exportados do Agili, cruza as matrículas com a planilha atual, descobre quem saiu e quem entrou, e atualiza tudo automaticamente no Google Sheets usando a API oficial.

🏗️

Arquitetura do Sistema

⚙️ config.py

O Cérebro das Constantes — Centraliza caminhos, IDs da planilha, mapeamento de colunas do CSV ("Text12" → "nome") e constantes como "EM ABERTO" para vagas livres.

🚀 main.py

O Maestro — Ponto de entrada que orquestra todo o fluxo: autentica no Google, lê CSVs, cruza dados e dispara as atualizações na planilha.

📄 csv_service.py

Leitor de Dados — Importa e normaliza os CSVs do Agili, lidando com encodings e separadores diferentes automaticamente.

📊 sheets_service.py

Conector Google — Gerencia autenticação via conta de serviço e executa leituras/escritas na planilha com batch updates.

🔄 transform_service.py

Inteligência de Cruzamento — Compara matrículas antigas e novas, gerando listas de inserção, remoção e atualização.

📝 utils/

Utilitários — Funções auxiliares de logging, validação de dados e formatação de saídas.

🛠️

Tecnologias Utilizadas

Python Linguagem principal da automação
Pandas Leitura de CSVs, cruzamento e filtragem de dados
gspread Comunicação simplificada com Google Sheets API
google-auth Autenticação segura via conta de serviço
Google Sheets API Atualização em lote (batch) da planilha
⚙️

Fluxo de Execução

1
Autenticação

Conexão segura com Google Sheets via conta de serviço

2
Leitura de CSVs

Importação e normalização dos arquivos exportados do Agili

3
Cruzamento de Dados

Comparação de matrículas para identificar entradas e saídas

4
Atualização em Lote

Batch update na planilha do Google Sheets com as alterações

5
Log e Relatório

Registro de todas as alterações realizadas para auditoria
