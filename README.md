# Portfólio - Michael Cachina

Este é o repositório do meu portfólio pessoal, desenvolvido com foco em performance, acessibilidade e design moderno (Dark Mode com Glassmorphism).

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estruturação semântica.
- **CSS3 (Vanilla)**: Estilização completa, variáveis CSS, animações e responsividade.
- **JavaScript (Vanilla)**: Lógica de rolagem suave e animações baseadas em scroll (Intersection Observer).

## 🛠️ Como modificar os Projetos
Para adicionar, remover ou modificar os projetos listados no portfólio, basta seguir estes passos:

1. Abra o arquivo `index.html` em qualquer editor de código (como o VS Code).
2. Procure pela seção com `id="projects"`.
3. Dentro dessa seção, você verá várias `div`s com a classe `project-card`.
4. Cada `project-card` representa um projeto. Você pode alterar o texto dentro das tags `<h3>` (Título do projeto) e `<p>` (Descrição do projeto).
5. Para alterar o link do botão "Ver Código", basta modificar o atributo `href` da tag `<a>` dentro desse card.
   
Exemplo:
```html
<div class="project-card">
    <div class="project-img-placeholder">Novo Projeto</div>
    <div class="project-info">
        <h3>Meu Super Projeto</h3>
        <p>Descrição incrível sobre o que este projeto faz.</p>
        <a href="URL_DO_SEU_GITHUB_AQUI" class="btn-link">Ver Código</a>
    </div>
</div>
```
